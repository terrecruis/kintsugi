\begin{decisione}{D0012}{Un solo codice per tutte le versioni}{Accettata}{22/10/2026}

\contesto
Le cinque versioni vanno confrontate in modo equo.

\scelta
Un solo repository e un solo codice: le versioni differiscono solo nella configurazione, non in copie separate del programma.

\conseguenze
Un errore corretto vale per tutte le versioni, quindi non falsa il confronto.

\end{decisione}
