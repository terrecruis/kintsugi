\begin{decisione}{D0007}{Come Kubernetes controlla che i servizi stiano bene}{Proposta}{22/10/2026}

\contesto
Kubernetes chiede periodicamente a ogni copia dell'API ``sei viva?'' e ``sei pronta?''. Se la risposta dipendesse dal database, quando il database si ferma tutte le copie verrebbero riavviate insieme, peggiorando il guasto.

\scelta
I due controlli verificano solo l'API stessa, non il database. Se il database è fermo, l'API risponde subito con un errore.

\conseguenze
Un guasto del database non trascina con sé l'API. Per il test F7 proviamo due frequenze di controllo (veloce e quella standard di Kubernetes).

\end{decisione}
