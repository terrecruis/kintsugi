\chapter{Decisioni architetturali}
\label{cap:decisioni}

Ogni decisione rilevante è documentata come \textit{Architecture Decision Record} (ADR): contesto, decisione presa, conseguenze. Una decisione non si cancella: se cambia, se ne scrive una nuova che la sostituisce. Ogni ADR è un file in \texttt{docs/chapters/decisioni/}.
