## Logo del frontespizio

Il frontespizio inserisce automaticamente il logo se trova uno di questi file:

- `logo-unina.pdf` (preferito, vettoriale)
- `logo-unina.png`

Il logo ufficiale dell'Università si scarica dal sito dell'Ateneo (sezione identità visiva / marchio). Se il file manca, il frontespizio resta solo testuale e compila comunque.
